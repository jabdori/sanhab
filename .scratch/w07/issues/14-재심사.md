# 14: 재심사

**What to build:** 승인은 났지만 지급 전인 건이 변경으로 승인권자가 올라가면, 지급이 재심사가 되고 올바른 승인권자의 승인을 다시 받는다. (시나리오 4 중간)

**Blocked by:** 13 변경, 07 지급

**Status:** done

- [ ] 영업지원이 한라인상사34의 6월 심사(1,353,657)를 승인해 지급이 대기인 상태에서 주소 변경을 넣는다
- [ ] 그 지급의 상태가 재심사가 되고 조치에서 지급이 사라진다. 사유로 변경이 보인다
- [ ] 앞선 승인은 기록으로 남되 효력을 잃고, 합쳐진 심사가 영업임원의 담당에 대기로 나타난다
- [ ] 영업임원이 승인하면 지급이 다시 대기가 된다
- [ ] 이미 지급이 완료된 건은 재심사가 되지 않는다(재검토가 될 뿐이다)
- [ ] 정황만으로는 재심사가 되지 않는다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
