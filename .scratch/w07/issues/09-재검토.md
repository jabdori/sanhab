# 09: 재검토

**What to build:** 원본의 과거 승인이 당시 모습 그대로 보이고, 현재 계산으로는 한도를 넘는 것에 재검토 표시가 붙는다. 당시와 현재가 나란히 보인다. (시나리오 3 앞부분)

**Blocked by:** 04 심사

**Status:** ready-for-agent

- [ ] 1~5월의 승인 196건과 반려 4건이 과거의 결정으로 적재된다. 승인권자는 원본대로 영업지원, 사유는 `사유 없음(원본)`, 인지일은 미상
- [ ] 과거의 승인은 당시 구성(단독)을 보존한다. 현재 구성으로 다시 계산한 결과를 옆에 붙인다
- [ ] 박상현 그룹의 1~5월이 재검토다. 현재 합산은 4,870,186 / 4,540,341 / 4,055,114 / 4,267,112 / 4,505,596, 현재 승인권자는 영업임원, 해당 지급은 15건, 합계 22,238,349
- [ ] 다른 대리점의 과거 승인에는 재검토가 없다
- [ ] 재검토인 심사의 가운데에 당시 / 현재 두 열(구성, 합산, 승인권자, 인지일)이 보이고 다른 줄만 굵다
- [ ] 재검토는 상태가 아니라 표시다. 승인이라는 상태는 그대로다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
