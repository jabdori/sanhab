# 23: 모의

**What to build:** 한도를 바꿔 보면 현재와 승인권자가 달라지는 심사가 세어지고 목록으로 보인다. 실제 판단은 바뀌지 않는다. (시나리오 8)

**Blocked by:** 22 규정

**Status:** ready-for-agent

- [ ] 영업임원과 내부 감시가 규정 화면의 조치에서 한도 값을 넣는다
- [ ] 코드가 모든 심사를 그 한도로 다시 계산해 `변동 n / 전체`와 현재 / 모의 두 열을 보여 준다
- [ ] 모의는 심사의 상태, 승인권자, 작업을 바꾸지 않는다
- [ ] 결과의 출처는 가정이다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
