# 03: 관련자

**What to build:** 대리점을 열면 누구와 관련자인지, 무엇이 일치하는지가 그림과 표로 보인다. 관련자는 저장하지 않고 조회할 때 계산한다.

**Blocked by:** 02 대리점

**Status:** ready-for-agent

- [ ] 식별자 셋 중 둘 이상이 글자 그대로 같으면 관련자다. 대표자는 이름이 같으면 일치로 본다
- [ ] 그룹은 관련자를 전이적으로 이은 것이다. 장려금 대상이 아닌 대리점도 그룹에 들어간다
- [ ] 금강상사11–성일상사24는 대표자·주소, 금강상사11–대륙상사37은 대표자·계좌로 관련자이고 세 곳이 한 그룹이다. 다른 그룹은 없다
- [ ] 한라인상사34와 금강상사41은 대표자만 같아 관련자가 아니다
- [ ] 관계 그림은 대리점을 둥근 모양, 사람·주소·계좌를 각진 모양의 점으로 그리고 바로 옆 이웃만 보여 준다. 같은 내용이 표로도 있다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
