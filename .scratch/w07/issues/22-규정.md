# 22: 규정

**What to build:** 메뉴의 규정에서 판단의 근거가 된 조항, 규칙 버전, 가정, AI가 하는 일을 볼 수 있다.

**Blocked by:** 04 심사

**Status:** ready-for-agent

- [ ] 조항의 원문과 문서 위치(파일, 행)가 보이고 출처는 원본이다
- [ ] 규칙(합산, 한도)의 버전과 시행 기간이 보인다. 새 버전은 이전 버전에 이어진다(선 27)
- [ ] 가정이 목록으로 보이고 각 가정이 쓰인 곳으로 갈 수 있다
- [ ] AI가 하는 일(조사, 요청서, 정리, 설명)과 하지 않는 일(판정)이 적혀 있다
- [ ] 심사 상세의 규정 줄에서 이 화면의 해당 조항으로 올 수 있다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
