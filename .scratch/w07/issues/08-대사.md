# 08: 대사

**What to build:** 지급 뒤 회계·자금이 은행 회신을 넣으면 승인 내용과 맞춰 본 결과가 찍히고, 일치하면 심사가 정산이 된다. (시나리오 1 끝)

**Blocked by:** 07 지급

**Status:** ready-for-agent

- [ ] 지급이 완료되면 대사 작업이 생긴다
- [ ] 회계·자금이 은행 회신(금액, 계좌, 결과)을 넣는다(모의 처리)
- [ ] 코드가 승인된 금액·등록된 계좌와 맞춰 보고 일치 또는 불일치를 찍는다. 가운데의 대사 표에 승인 / 회신 / 비교가 보인다
- [ ] 심사의 지급이 모두 일치이면 심사에 정산 표시가 붙는다
- [ ] 불일치는 기록으로 남는다(정황으로 접수하는 것은 정황 티켓에서 잇는다)
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
