# 07: 지급

**What to build:** 승인된 심사마다 회계·자금에 지급 작업이 생기고, 회계·자금이 지급으로 표시한다. (시나리오 1 중간)

**Blocked by:** 04 심사

**Status:** done — `w07`에 합침. Codex 검토 결함 없음, 화면 검수 2회차 통과(`.scratch/w07/review/t07/r2/`)

- [x] 심사가 승인되면 그 심사의 지급마다 회계·자금의 담당에 지급 작업이 생긴다
- [x] 지급 상세: 가운데에 대리점, 귀속월, 금액, 계좌. 오른쪽 조치에 지급

- [x] 다른 역할은 지급할 수 없다
