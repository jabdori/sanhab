# 07: 지급

**What to build:** 승인된 심사마다 회계·자금에 지급 작업이 생기고, 회계·자금이 지급으로 표시한다. (시나리오 1 중간)

**Blocked by:** 04 심사

**Status:** ready-for-agent

- [ ] 심사가 승인되면 그 심사의 지급마다 회계·자금의 담당에 지급 작업이 생긴다
- [ ] 지급 상세: 가운데에 대리점, 귀속월, 금액, 계좌. 오른쪽 조치에 지급
- [ ] 회계·자금이 지급을 누르면 상태가 완료가 된다. 은행 연동은 없다(모의 처리)
- [ ] 목록 위에 `대기 n  재심사 n  완료 n`이 보인다
- [ ] 다른 역할은 지급할 수 없다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
