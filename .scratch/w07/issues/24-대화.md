# 24: 대화

**What to build:** 오른쪽 끝의 대화를 펼쳐 물으면 AI가 DB를 읽어 답한다. 지금 보고 있는 대상을 따라가고, 임시라서 기록으로 남지 않는다.

**Blocked by:** 17 보고

**Status:** ready-for-agent

- [ ] 대화는 어느 화면에서든 오른쪽 끝에 접혀 있다. 펼치면 목록이 접히고 가운데와 오른쪽은 그대로 보인다. 머리에 대화와 임시가 보인다
- [ ] 답이 조각조각 흘러나온다. 화면은 AI SDK의 대화 부품으로 받는다(`docs/spike/`)
- [ ] 지금 열어 둔 대상이 문맥으로 따라오고 끌 수 있다. 화면의 다른 기록을 붙일 수 있다
- [ ] AI는 DB를 읽는 도구만 쓴다. 답 아래에 조회한 기록 목록을 코드가 붙인다
- [ ] 승인해도 되는지 같은 질문에는 사실과 규정을 답하고 판정 의견은 내지 않는다
- [ ] 대화는 그래프에 남지 않고 경위에도 나타나지 않는다. 보고를 누르면 검증을 거쳐 보고로 저장된다
- [ ] AI가 멈춰 있어도 나머지 화면은 그대로 된다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
