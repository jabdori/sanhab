# 12: 가설

**What to build:** 정황이 사실이라고 놓았을 때 그룹·합산·승인권자가 어떻게 달라지는지 보이고, 승인권자가 올라가는 심사는 영업임원에게 간다.

**Blocked by:** 11 정황

**Status:** ready-for-agent

- [ ] 정황 상세와 심사 상세에 현재 / 가설 두 열(일치, 그룹, 승인권자)이 보인다
- [ ] 계좌 정황의 가설: 성일상사24–대륙상사37의 일치가 대표자에서 대표자·계좌가 된다. 지금은 세 곳이 이미 한 그룹이라 승인권자는 변동 없음
- [ ] 동명과 근접 정황의 가설은 승인권자를 바꾸지 않는다
- [ ] 가설에서 승인권자가 올라가는 심사는 영업지원이 승인할 수 없고 영업임원의 담당으로 간다(가정). 변동이 없는 정황은 보여 주기만 한다
- [ ] 가설은 합산과 실제 승인권자 계산에 들어가지 않는다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
