# 18: 발송

**What to build:** 내부 감시가 정황에서 요청을 고르면 영업지원이 대리점에 보낼 요청서를 발송으로 표시하고, 소명이 요청 상태로 열린다.

**Blocked by:** 11 정황, 17 보고

**Status:** done

- [ ] 내부 감시가 요청을 고르면 소명이 만들어지고(상태 요청) 영업지원의 담당에 발송 작업이 생긴다
- [ ] 요청서에는 일치 종류에 따라 정해진 서류 목록이 들어간다. 주소: 임대차계약서·사업자등록증. 계좌: 통장 사본·예금주 확인서. 대표자: 생년월일을 확인할 수 있는 서류(목록은 가정)
- [ ] AI가 요청서 초안을 쓰고 영업지원이 고쳐서 발송으로 표시한다. 실제로 보내지는 않는다(모의 처리). AI가 멈춰 있으면 목록만으로 발송할 수 있다
- [ ] 소명에 기한이 붙는다(길이는 가정)
- [ ] 소명이 끝나기 전에는 그 대리점을 관련자로 계속 본다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
