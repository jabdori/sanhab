# 25: 조치 카드

**What to build:** 대화에서 사람이 사유와 함께 조치를 지시하면 AI가 조치 카드를 그리고, 사람이 실행을 눌러야 그 사람의 권한으로 실행된다.

**Blocked by:** 24 대화, 05 승인권자

**Status:** ready-for-agent

- [ ] AI는 조치를 실행하지 못한다. 대상, 조치, 사유(분류와 메모)를 채운 카드를 대화 안에 그린다
- [ ] 카드의 모양과 버튼은 우리 부품으로 고정되어 있다
- [ ] 사유는 사람이 말한 것을 옮겨 적은 것이고, 사람이 카드에서 고칠 수 있다
- [ ] 실행을 누르면 그 사람의 역할 권한으로 실행되고, 결과는 화면에서 직접 한 조치와 똑같이 이력과 경위에 남는다
- [ ] 지금 역할에 권한이 없는 조치는 카드로 그려지지 않는다
- [ ] 사유가 필수인 조치는 카드에서도 사유 없이는 실행되지 않는다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
