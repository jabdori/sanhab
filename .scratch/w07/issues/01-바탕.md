# 01: 바탕

**What to build:** 접속 패스워드를 넣고 역할을 고르면 띠와 빈 메뉴가 뜬다. 이후 모든 티켓이 올라설 뼈대다. 기존 서버에서 판정·화면 코드를 걷어 내고 DB 연결, 역할별 권한 세션, 원본 CSV 읽기, 배포 구성만 남긴다. 화면은 React + Base UI + Tailwind + jotai로 새로 시작하고 빌드 결과를 서버 실행 파일에 포함한다.

**Blocked by:** 없음 (바로 시작할 수 있음)

**Status:** ready-for-agent

- [ ] 접속 패스워드 없이는 어떤 자료 요청도 거절된다
- [ ] 패스워드를 넣으면 역할(영업지원, 영업임원, 내부 감시, 회계·자금)을 고를 수 있고, 띠에서 바꿀 수 있다
- [ ] 띠에 역할, 날짜 2026-07-01, 초기화가 보인다. 초기화는 확인 창을 거쳐 DB를 원본 상태로 되돌린다
- [ ] 메뉴는 작업·대리점·규정 셋이고, 본문은 목록 / 가운데 / 오른쪽 / 대화 손잡이의 자리를 갖는다(내용은 `없음`)
- [ ] 색·글자·간격은 `docs/design/tokens.md`의 값을 한 파일에 정의해 쓰고, 화면의 낱말은 한 파일에 모은다(`docs/design/copy.md`)
- [ ] Pretendard가 앱에 포함되어 바깥 서버 없이 뜬다
- [ ] 로컬 compose로 띄운 것과 같은 구성이 AXHub 배포 조건(포트 선언, DB 사용자, 매니페스트)을 그대로 지킨다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
