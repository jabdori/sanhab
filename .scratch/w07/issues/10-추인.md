# 10: 추인

**What to build:** 재검토가 된 과거의 승인을 영업임원이 추인하고, 내부 감시가 종결한다. (시나리오 3 뒷부분)

**Blocked by:** 09 재검토, 05 승인권자

**Status:** done

- [ ] 재검토가 되면 영업임원의 담당에 추인 작업이 생긴다
- [ ] 영업임원은 추인하거나 거부한다(둘 다 사유 필수, D52). 거부하면 과거의 승인은 그대로이고 재검토 표시가 남으며 거부 표시가 붙고, 추인 작업이 끝나고, 종결 작업은 생기지 않는다
- [ ] 영업임원이 추인하면(사유 필수) 심사에 추인 표시가 붙고, 내부 감시의 담당에 종결 작업이 생긴다
- [ ] 내부 감시는 종결하거나, 종결하지 않고 의견을 남긴다(이때 사유 필수). 승인을 뒤집지는 못한다
- [ ] 종결되면 심사에 종결 표시가 붙는다
- [ ] 추인은 과거의 승인에 이어진다(선 30). 과거의 승인 기록은 바뀌지 않는다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
