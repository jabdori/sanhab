# 11: 정황

**What to build:** 코드가 찾은 정황이 내부 감시의 작업에 올라오고, 내부 감시가 근거를 보고 요청 또는 기각한다.

**Blocked by:** 05 승인권자

**Status:** ready-for-agent

- [ ] 코드가 세 종류를 빠짐없이 찾는다. 계좌: 성일상사24의 회수 2건의 계좌가 금강상사11·대륙상사37의 계좌와 같다. 동명: 한라인상사34와 금강상사41. 근접: 금액이 1,800,000~2,000,000인 지급 3건(기준은 가정)
- [ ] 같은 대상의 같은 종류 정황은 하나로 모은다
- [ ] 정황은 지급을 막지 않는다. 정황이 걸린 심사에는 정황 표시가 붙고 작업 목록에서 위로 올라온다
- [ ] 정황 상세: 가운데에 제목 줄, 근거 표(가리키는 기록의 값을 코드가 채움), 관계. 오른쪽 조치에 요청·기각
- [ ] 내부 감시만 요청 또는 기각할 수 있다. 기각에는 사유가 필수다. 누가 정했는지가 남는다(선 28)
- [ ] 대사의 불일치가 대사 정황으로 접수된다(대사 티켓이 끝나 있으면)
- [ ] 정황이 걸린 심사를 승인할 때는 사유가 필수가 된다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
