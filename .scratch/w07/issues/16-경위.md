# 16: 경위

**What to build:** 어느 작업이나 상태에서든 그것이 무엇 때문에 생겼는지를 처음의 사건까지 거슬러 볼 수 있다. (시나리오 4 끝)

**Blocked by:** 13 변경, 07 지급

**Status:** done (화면 검수 전)

- [ ] 사건, 결정, 소명이 만들고 바꾼 것이 원인 선으로 이어진다(선 25)
- [ ] 오른쪽 경위 칸에 시간순 목록(날짜, 종류, 대상)이 보인다
- [ ] 펼치면 가운데가 그림으로 바뀐다. 원인은 왼쪽, 결과는 오른쪽이고 방향은 바뀌지 않는다. 지금 대상의 줄기가 진하다
- [ ] 주소 변경 뒤 재심사인 지급의 경위가 승인 → 변경 → 재심사로 이어진다. 추인 작업의 경위가 변경 → 재검토 → 작업으로 이어진다
- [ ] 그림의 칸을 누르면 그 대상으로 간다. 결정의 칸에는 사람과 사유가 붙는다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
