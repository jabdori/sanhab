# 26: 대화 서류

**What to build:** 대화에 파일을 올리면 AI가 그것을 소명의 서류로 넘기고, 소명 화면에서 올린 것과 똑같은 절차를 거친다.

**Blocked by:** 24 대화, 19 서류

**Status:** ready-for-agent

- [ ] 대화에 올린 파일은 AI가 도구로 소명에 넘긴다. 어느 소명의 것인지 정해지지 않으면 묻는다
- [ ] 넘겨진 파일은 판독·정리·비교를 똑같이 거치고 소명 상세에 나타난다
- [ ] 요청 상태의 소명이 없으면 넘기지 않고 그 사실을 답한다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
