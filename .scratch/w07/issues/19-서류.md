# 19: 서류

**What to build:** 영업지원이 소명의 서류를 올리면 판독·정리·비교가 원본과 나란히 보인다. (시나리오 5, 6의 가운데)

**Blocked by:** 18 발송, 17 보고

**Status:** ready-for-agent

- [ ] 영업지원이 요청 상태의 소명에 서류를 올리면 소명이 접수가 되고 내부 감시의 담당에 소명 작업이 생긴다
- [ ] 업스테이지 API가 글자와 위치를 읽는다(판독). AI가 필요한 항목(호실, 임차인, 기간 등)에 해당하는 조각을 가리키고 값을 다듬는다(정리)
- [ ] 코드가 정리된 값을 상대 대리점의 등록 값과 맞춰 일치 / 불일치 / 누락을 찍는다
- [ ] 소명 상세: 가운데 왼쪽에 서류 원본, 오른쪽에 값 표(항목, 판독, 등록, 비교). 정리된 값은 오른쪽 보고에 있다. 값의 줄과 원본의 위치가 서로 강조된다
- [ ] 누락·불일치인 줄이 위에 온다. 서류 원본은 언제나 볼 수 있다
- [ ] 서류는 다시 배포해도 남는 곳에 저장한다
- [ ] 시연용 서류 세 장이 준비되어 있고 출처가 시연이다: 호실이 다른 임대차계약서, 호실까지 같은 임대차계약서, 호실이 빠진 서류
- [ ] 글자 인식이나 AI가 멈춰 있으면 원본만 보이고 값은 `없음`이다. 내부 감시는 그대로 결정할 수 있다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
