# 20: 소명

**What to build:** 내부 감시가 서류를 보고 인정·불인정·보완을 정한다. 인정하면 그 일치가 관련자 계산에서 빠지고 그룹이 다시 계산된다. (시나리오 6, 5의 끝)

**Blocked by:** 19 서류

**Status:** ready-for-agent

- [ ] 내부 감시만 인정·불인정·보완을 정할 수 있고 셋 다 사유가 필수다(선 19)
- [ ] 보완이면 영업지원에 발송 작업이 다시 생기고, 그동안 관련자로 계속 본다
- [ ] 불인정이면 관련자가 유지된다
- [ ] 인정이면 그 대리점의 해당 식별자 선에 소명으로 제외가 붙고 관련자 계산에서 빠진다. 효력은 서류가 입증하는 기간을 따른다
- [ ] 성일상사24의 주소 소명(금강상사11과 호실이 다름)을 인정하면 6월 심사가 {금강상사11, 대륙상사37} 합산 2,699,051과 성일상사24 1,189,046으로 갈라진다
- [ ] 그 뒤에도 계좌 정황의 가설에서 성일상사24의 승인권자가 올라가므로 성일상사24의 심사는 영업임원의 담당이다
- [ ] 한라인상사34의 주소 소명을 인정하면 금강상사41과 다시 관련자가 아니게 되고, 2·3월의 재검토가 풀리며 6월 심사가 각각 영업지원의 것으로 돌아간다(변경 티켓이 끝나 있으면)
- [ ] 호실까지 같은 서류에는 비교가 일치로 찍히고 보고의 미확인에 추가 확인이 적힌다
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
