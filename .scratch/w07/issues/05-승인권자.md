# 05: 승인권자

**What to build:** 합산이 한도를 넘는 심사는 영업지원에게 조치가 없고 영업임원이 승인하거나 보류한다. 사유의 분류와 필수 규칙이 동작한다. (시나리오 2, 7의 보류)

**Blocked by:** 04 심사

**Status:** ready-for-agent

- [ ] 박상현 그룹의 6월 심사는 `합산 3,888,097  한도 2,000,000  승인권자 영업임원`이다. 구성 표의 일치 열에 대표자·주소·계좌, 대표자·주소, 대표자·계좌가 보인다
- [ ] 영업지원으로 열면 조치 자리에 버튼 대신 `승인권자 영업임원`이 보이고, 요청을 직접 보내도 거절된다
- [ ] 영업임원은 승인 또는 보류를 고른다. 보류는 지급 작업을 만들지 않고 금액은 6월 합산에 그대로 남는다
- [ ] 사유는 분류(고르기)와 메모로 받는다. 보류에는 분류가 필수이고, 기타를 고르면 메모가 필수다. 비어 있으면 조치가 눌리지 않는다
- [ ] 정황이 없는 심사의 승인에는 사유가 없어도 된다
- [ ] 사유는 결정한 사람과 시각과 함께 남는다(선 13)
- [ ] 이 티켓의 숫자와 상태 변화를 확인하는 자동 검사가 통과한다
- [ ] 별도 에이전트의 화면 검수(`docs/design/review.md`)에서 막힘과 어김이 없다
