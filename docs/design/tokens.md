# 디자인 기준 (디자인 하네스)

조용하고 밀도 있는 업무 도구. 흰 바탕에 표와 글자가 중심이고 색은 상태를 알릴 때만 쓴다. 근거: `docs/service-plan.md` S5·S6·U6·U8~U10.
값은 `app/web/src/theme.css` 한 곳에 정의하고, 부품은 그 이름만 쓴다. 부품 안에 색·크기 숫자를 직접 적지 않는다.

## 색
| 이름 | 값 | 쓰임 |
|---|---|---|
| `bg` | `#FFFFFF` | 바탕 |
| `surface` | `#F7F7F8` | 띠, 메뉴, 표 머리글, 오른쪽 칸 |
| `line` | `#E4E4E7` | 선, 칸의 경계 |
| `text` | `#18181B` | 글자 |
| `text-sub` | `#52525B` | 보조 글자, 이름표 |
| `text-mute` | `#A1A1AA` | "없음", 비활성, 그림의 선 |
| `action` | `#1D4ED8` | **누를 수 있는 것에만.** 다른 뜻으로 쓰지 않는다 |
| `action-hover` | `#1E40AF` | |
| `mark` | `#FEF9C3` | 근거·원본 위치의 강조(일시적) |

상태 표지(알약)에만 쓰는 색. 바탕 / 글자.
| 상태 | 바탕 | 글자 | 화면 표기 |
|---|---|---|---|
| 대기 | `#F4F4F5` | `#3F3F46` | 대기, 접수, 요청, 검토 |
| 좋음 | `#DCFCE7` | `#166534` | 승인, 인정, 일치, 완료, 채택 |
| 멈춤 | `#FEF3C7` | `#92400E` | 보류, 보완, 미응답 |
| 아님 | `#FEE2E2` | `#991B1B` | 반려, 불인정, 불일치, 누락, 오류, 불채택 |
| 다시 | `#EDE9FE` | `#5B21B6` | 재심사 |

- 덧붙는 표시(재검토, 정황, 추인, 확인, 정산)는 색 없이 아이콘 + 글자(`text`).
- 출처과 "AI"는 색 없이 테두리(`line`) 글자(`text-sub`).
- 색만으로 뜻을 전하지 않는다. 항상 글자가 함께 있다.
- 어두운 화면(다크 모드)은 만들지 않는다.

## 글자
- 글꼴: Pretendard(파일을 앱에 포함, 바깥 서버에서 불러오지 않는다). 대체: 시스템 글꼴.
- 금액·계좌번호·날짜: 고정폭 숫자(`font-variant-numeric: tabular-nums`), 금액은 오른쪽 정렬, 천 단위 쉼표, "원"은 붙이지 않는다.

| 이름 | 크기 / 줄 높이 / 굵기 | 쓰임 |
|---|---|---|
| `title` | 16 / 24 / 600 | 상세의 제목(대상 이름) |
| `figure` | 14 / 20 / 600 | 숫자 줄의 값 |
| `body` | 14 / 20 / 400 | 본문, AI가 쓴 글 |
| `table` | 13 / 18 / 400 | 표 |
| `label` | 12 / 16 / 500 | 이름표, 표 머리글, 표지 |

## 간격과 모양
- 간격은 4의 배수만: 4, 8, 12, 16, 24, 32.
- 모서리: 4. 상태 표지만 알약(999). 예외: 관계 그림의 대리점 점은 둥근 모양(사람·주소·계좌 점은 각진 모양).
- 관계 그림과 경위 그림의 색: 점의 테두리 `text-sub`, 선 `text-mute`, 글자 `text`, 바탕 `bg`.
- 선: 1px `line`. 그림자는 띄운 것(말풍선, 확인 창)에만.
- 표의 줄 높이 36, 머리글 32.
- 표의 칸은 줄을 바꾸지 않는다. 자리가 좁아 표가 넘치면 그 표만 가로로 민다(화면 전체는 가로로 넘치지 않는다).
- 숫자 줄의 항목(이름표 + 값)은 쪼개지지 않는다. 폭이 모자라면 항목 단위로 다음 줄로 넘어간다.

## 자리의 폭 (기준 1440 × 900, 최소 1280)
| 자리 | 폭 |
|---|---|
| 띠 | 높이 44 |
| 메뉴 | 96 |
| 목록 | 상세가 닫혔을 때 나머지 전부, 열렸을 때 360, 대화를 펼치면 0 |
| 가운데(사실) | 나머지 |
| 오른쪽(판단) | 360 |
| 대화 | 접힘 40, 펼침 380 |

## 움직임
- 강조(`mark`)는 1.2초 뒤 사라진다. 그 밖의 움직임은 칸이 열리고 닫히는 150ms뿐이다.
