# 부품 목록 (디자인 하네스)

화면은 아래 부품만으로 만든다. 새 부품이 필요하면 이 표에 먼저 더한다. 동작이 있는 부품은 Base UI(`@base-ui/react`)의 것을 쓰고 모양은 `tokens.md`의 이름으로만 입힌다.
화면에 보이는 낱말은 모두 `app/web/src/labels.ts` 한 파일에 둔다(`copy.md`의 화면 표기 표를 옮긴 것). 부품 안에 글자를 직접 적지 않는다.

## 틀
| 부품 | 쓰임 | 규칙 |
|---|---|---|
| 띠 | 앱 이름, 현재 역할, 현재 날짜, 역할·날짜·초기화 | 항상 보인다. 역할 고르기는 Base UI Select, 초기화는 확인 창을 거친다 |
| 메뉴 | 작업·대리점·규정 | 셋만 |
| 목록 | 작업 목록, 대리점 목록 | 상세가 열리면 좁아진다. 탭(담당·진행)은 Base UI Tabs |
| 상세 | 가운데(사실)와 오른쪽(판단) 두 칸 | 가운데에 AI가 쓴 글을 넣지 않는다 |
| 판단 칸 | 조치 → 사유 → 보고 → 경위 → 이력 | 순서 고정. 해당 없으면 "없음" |
| 대화 칸 | 전역 대화 | 오른쪽 끝. 머리에 "대화"와 "임시" |

## 사실을 보여 주는 부품 (가운데)
| 부품 | 쓰임 | 규칙 |
|---|---|---|
| 제목 줄 | 대상 이름 · 귀속월 + 상태 표지 + 덧표시 | 한 줄 |
| 숫자 줄 | `합산 3,888,097  한도 2,000,000  승인권자 영업임원` | 이름표(`label`) + 값(`figure`). 문장으로 쓰지 않는다 |
| 표 | 구성, 근거, 값, 대사 | 금액은 오른쪽 정렬·고정폭. 첫 열은 사람이 읽는 이름. 줄에 조치 버튼을 두지 않는다 |
| 두 열 비교 | 당시 / 현재, 현재 / 가설, 현재 / 모의 | 다른 줄만 굵게 |
| 관계 그림 | 대리점과 사람·주소·계좌 | 대리점은 둥근 모양, 식별자는 각진 모양. 한 대상의 바로 옆 이웃만. 방향 고정. 같은 내용의 표가 반드시 함께 있다 |
| 서류 대조 | 원본 이미지 + 값 표 | 값의 줄과 원본의 위치가 서로 강조된다 |
| 경위 그림 | 원인 → 결과 | 왼쪽에서 오른쪽. 지금 대상의 줄기를 진하게 |

## 판단에 쓰는 부품 (오른쪽)
| 부품 | 쓰임 | 규칙 |
|---|---|---|
| 조치 | 승인·보류·반려 등 | 권한이 없으면 버튼 대신 `승인권자 영업임원`. 버튼의 무게는 모두 같다(한 버튼만 강조하지 않는다) |
| 사유 | 분류(Base UI Select) + 메모 | 필수인 결정에서 분류가 비면 조치가 눌리지 않는다. "기타"면 메모 필수 |
| 보고 | 사실 / 추정 / 미확인 / 의견·반론 | 머리에 "AI"와 상태 표지. "사실"의 문장 끝에 근거 연결. "미확인"은 접지 않는다. "의견"은 접힘(Base UI Collapsible). 확신을 숫자로 적지 않는다 |
| 근거 연결 | `↗` | 누르면 가운데의 해당 줄·위치가 `mark`로 강조된다 |
| 경위 목록 | 날짜 · 종류 · 대상 | 시간순. 펼치면 가운데가 경위 그림으로 |
| 이력 | 결정 · 사람 · 날짜 · 사유 | 원본의 과거 결정은 `사유 없음(원본)` |

## 표시
| 부품 | 쓰임 | 규칙 |
|---|---|---|
| 상태 표지 | 처리 상태 | 알약. 색은 `tokens.md`의 다섯 가지뿐 |
| 덧표시 | 재검토·정황·추인·확인·정산 | 아이콘 + 글자, 색 없음 |
| 출처 표지 | 원본·계산·가정·AI·시연 | 테두리 글자. 누르면 어디서 왔는지 열린다(Base UI Popover): 원본 파일과 행, 계산식, 가정 항목, AI 실행 기록 |
| 빈 자리 | 내용이 없을 때 | `없음`만. 그림이나 안내 문장을 두지 않는다 |

## 대화
| 부품 | 쓰임 | 규칙 |
|---|---|---|
| 문맥 줄 | 지금 따라가는 대상 | 끌 수 있다. 붙인 기록은 칩으로 |
| 말 | 사람의 말, AI의 답 | AI의 답 아래에 조회한 기록 목록(코드가 붙임) |
| 조치 카드 | AI가 그린 조치 제안 | 대상, 조치, 사유를 보여 주고 "확인"으로 실행. 권한 없는 조치는 그리지 않는다 |
| 보고로 남기기 | 대화 내용을 기록으로 | 검증을 통과해야 저장 |
