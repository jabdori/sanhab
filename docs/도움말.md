# 도움말

앱 안의 도움말(메뉴 레일의 물음표)과 같은 내용이다. 고칠 때는 `app/web/src/labels.ts`의 `HELP`와 함께 고친다.

## 판매장려금

회사가 대리점에 주는 판매장려금은 대리점 한 곳에 한 달 200만 원까지 영업지원이 전결하고, 넘으면 영업임원이 승인합니다. 이름이 달라도 대표자 · 주소 · 계좌 가운데 둘 이상이 같은 대리점(관련 거래처)은 한 곳으로 보고 지급을 합쳐 한도를 봅니다. 예: 금강상사11 · 성일상사24 · 대륙상사37은 따로 보면 모두 한도 안이지만, 6월 지급을 합치면 3,888,097원입니다.

## 역할

| 역할 | 하는 일 |
|---|---|
| 영업지원 | 대리점별 월 지급을 심사해 승인 · 반려 · 보류합니다. 대리점의 서류를 받아 올립니다. |
| 영업임원 | 한도를 넘는 심사를 승인하고, 지급한 뒤에 관련 거래처로 밝혀진 달을 추인하거나 거부합니다. |
| 내부 감시 | 관련 거래처일 수 있다는 단서(정황)를 보고 소명을 요청하거나 기각하고, 받은 서류로 인정 · 불인정 · 보완을 정합니다. |
| 회계·자금 | 승인된 지급을 보내고, 은행 회신과 금액 · 계좌가 맞는지 대사합니다. |

## 낱말

| 낱말 | 뜻 |
|---|---|
| 관련 거래처 | 대표자 · 주소 · 계좌 가운데 둘 이상이 같은 대리점들. 지급을 합쳐 한도를 봅니다 |
| 합산 | 관련 거래처까지 합친 그달의 지급액 |
| 한도 | 영업지원이 혼자 승인할 수 있는 한 달 금액(200만 원) |
| 승인권자 | 합산이 한도 안이면 영업지원, 넘으면 영업임원 |
| 정황 | 관련 거래처일 수 있다는 단서. 내부 감시가 판정합니다 |
| 소명 | 정황에 대해 대리점에게 받는 설명과 서류 |
| 추인 | 이미 나간 지급을 나중에 승인하는 것 |
| 재심사 | 승인 뒤에 관련 거래처가 밝혀져 지급을 멈추고 다시 보는 것 |
| 대사 | 은행 회신과 보낸 금액 · 계좌를 맞춰 보는 것 |
| 출처 표지 | 원본에 없는 값에 붙습니다: 계산 · 가정 · 합성 · AI · 모의 · 예시 |

## 안내(둘러보기)

역할마다 처음 들어올 때 한 번 뜨고, 도움말의 `안내`로 다시 본다. 단계마다 제목과 한 줄(여기가 무엇이고 무엇을 하는지)만 보인다.

**예시 이야기**: 예시상사A(6월 1,200,000원)와 예시상사B(6월 1,100,000원)는 대표자만 같다. 일치가 하나라 따로 심사하고 둘 다 한도 안이다. 그런데 예시상사A의 회수금이 예시상사B의 계좌(예시은행 100-200-300)로 들어간 정황(계좌)이 있다. 정황이 맞으면 일치가 대표자 · 계좌 둘이 되어 관련 거래처가 되고, 합산 2,300,000원으로 한도를 넘는다. 정황이 있는 것만으로 심사는 영업임원에게 넘어간다(D8). 관련자를 확정하는 것은 내부 감시의 소명 판단이다(D12 · D13).

| 역할 | 예시 기록 | 문제가 드러나는 장면 | 대화(예시) |
|---|---|---|---|
| 영업지원 | 심사 예시상사A · 2026-06: 1,200,000원, 승인 단추 | 정황이 생김: 가설(일치 대표자 → 대표자 · 계좌, 1곳 → 2곳, 승인권자 영업지원 → 영업임원), 단추 대신 승인권자 영업임원 | 예시상사A 승인해도 돼? |
| 내부 감시 | 정황 계좌 · 예시상사A: 요청 · 기각 | 근거(예시상사A의 회수 → 예시은행 100-200-300, 예시상사B의 계좌 등록)와 관계 그림 | 두 곳이 관련됐다는 근거 정리해 줘 |
| 영업임원 | 추인 예시상사A 외 1 · 2026-05: 2,300,000원 | 재검토 표: 당시 단독 · 영업지원 → 현재 2곳 · 영업임원 | 5월 지급이 왜 다시 올라왔어? |
| 회계·자금 | 지급 예시상사A · 2026-06: 1,200,000원, 지급 단추 | 예시상사A의 계좌가 예시상사B와 같은 계좌로 바뀌어(대표자도 같아 일치 2) 재심사로 멈춤, 새 심사 예시상사A 외 1 | 이 지급 왜 멈췄어? |

요약 단계는 그 기록에 실제로 있는 것만 말한다. 영업지원 · 내부 감시는 `AI 보고` 단계에서 사실 영역 바로 아래의 AI 보고 카드를 밝힌다(D63). 예시는 화면에서만 보이고(서버와 DB는 그대로), `예시` 표지가 붙으며, 단추를 눌러도 실행되지 않는다. 끝나면 실제 작업 목록으로 돌아온다. 예시 응답은 `app/web/src/ui/example.json`.
