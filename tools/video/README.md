# 시연 영상 하네스

시연 영상은 이 절차로만 만든다. 관문을 넘지 못한 장면은 렌더되지 않는다(`make.sh`가 멈춘다). 대본과 장면 구성은 `docs/video/storyboard.md`.

## 절차
1. **대본**: 장면 설정 `scenes/sN.json`의 `lines`(문장), `groups`(한 번에 만들 단락), `cues`(이 문장의 이 낱말 ↔ 이 상자). 단서의 낱말은 그 값이 화면에 표시되는 순간 들려야 하는 낱말이다.
2. **음성**: `tts.py` — 단락마다 ElevenLabs로 한 번에 만들고 글자별 실제 시각을 저장한다. 문장마다 따로 만들지 않는다(이음매가 끊긴다).
3. **녹화**: 장면 녹화 스크립트(`scenes/recN.sh`, `lib.sh`를 source). 화면은 `cdp-rec.mjs`가 배율 3 스크린샷(3840×2160, 초당 약 30장)으로 찍고 `stitch.py`가 정확한 30fps로 묶는다 — agent-browser 녹화기는 배율과 상관없이 1280×720을 키워 아이콘 선이 뭉개지므로 커서를 그리는 데만 쓴다.
   - `prep`: 1280×720 · 3배, 네 역할의 안내를 본 것으로 기록(온보딩이 찍히지 않는다).
   - 값을 가리킬 때는 `pt "<화면 글 또는 css:/h2:>"`: 이름표와 시각을 커서가 움직이기 **시작할 때** 기록하고, 커서는 값의 오른쪽 아래 **바깥**에 선다(글을 가리지 않는다).
   - 화면이 바뀌는 동작(`tap`, `scrollto`, `top`, `typeslow`, 역할 전환)은 먼저 상자를 지운다.
   - 녹화는 배포본이 아니라 로컬 앱(실제 모델 응답)에서 한다. 시나리오가 데이터를 바꾸므로 녹화 전후 `reset_demo`.
4. **편집 · 검증**: `build.py` — 화면이 기준. 해설 문장을 상자가 뜨는 순간에 놓고, 상자가 이르면 그 직전에 화면을 멈추고, 늦으면 커서가 서 있는 구간만 잘라 낸다. **속도는 바꾸지 않는다(빨리 감기 없음).**
5. **겹 그림 · 렌더**: `compose.py` → hyperframes lint → render → ffmpeg로 음성 합치기.

## 관문(하나라도 실패하면 렌더하지 않는다)
| 관문 | 기준 |
|---|---|
| 준비 | 녹화 기록에 `prep tour=true viewport=1280x720x3` |
| 상자 | 녹화 중 못 찾은 상자 없음, 대본의 모든 단서에 상자가 있음 |
| 음성 | `voice.json`의 문장이 지금 대본과 같음 |
| 싱크 | 모든 단서에서 상자가 뜨는 시각과 낱말이 들리는 시각의 차이 ≤ 0.5초(4K 캡처 중 화면이 조금 느려지는 차이를 허용, 2026-11-15 0.3→0.5)(ElevenLabs 글자 시각 기준) |
| 멈춤 | 한 번의 화면 멈춤 ≤ 6.5초(넘으면 녹화 동작을 대본 쪽으로 당긴다) |
| 상자 남음 | 화면이 바뀐 뒤까지 남는 상자 없음 |
| 화면 · 해설 글 | 해설 문장과 화면에 얹는 모든 글(제목, 부제, 단계 칩)에 면책 · 안심 문구, 개발용 표기, 영문자+숫자 번호(`W07`, `S12`, `D-011`) 없음(`docs/design/review.md` 2 · 2-1절) |
| 길이 | 렌더본 길이 = 계획 길이(±0.2초) |

결과는 작업 폴더의 `verify.txt`. 보고할 때 이 표를 함께 낸다.

## 화면 위에 얹는 것
카메라(해설이 말하는 큰 영역으로만, 최대 1.3배, 헤더로는 다가가지 않는다), 말하는 값 상자, 아래쪽 단계 칩, `실제 작동`/`모의 처리` 표지, 자막, 처음 2초 제목. 그 밖의 효과(빛줄기, 손글씨, 화면 전환, 클릭 소리)는 쓰지 않는다.
